# FunTime

Игры для компании в браузере: React + TypeScript, Feature-Sliced Design, RTK Query и микросервисы на Go.

Реализовано «Мировое господство»: комнаты по коду, выбор страны и роли, пульт ведущего, публичный экран, шесть раундов, общий план команды, дипломатические встречи, серверный расчёт и итоговая история атак.

## Запуск

Нужны Node.js 24, npm и Go 1.26 или новее. В PowerShell:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте **http://127.0.0.1:5173**. Запускаются Catalog, Gateway, Room, World Domination и Vite. Остановка — Ctrl+C. После изменения Go перезапустите dev; React обновляется автоматически.

Локально комнаты и партии сохраняются в `.cache/data/room` и `.cache/data/world-domination`. Это данные игры: удаление этих каталогов удалит сохранённые комнаты. Перезапуск процессов сохраняет сессии, планы, таймеры и историю.

## Как показать игру

1. На карточке игры нажмите «Об игре», введите имя ведущего и создайте комнату.
2. Передайте ссылку или шестизначный код игрокам. Для проверки на одном компьютере используйте разные профили браузера или отдельный приватный сеанс.
3. Игроки выбирают страну и свободную роль. Нужны минимум две страны, хотя бы по одному игроку. Ведущий может играть или остаться вне команд.
4. Ведущий открывает «Общий экран» для проектора. Его собственный пульт содержит закрытую информацию.
5. Запустите игру. Стандартная фаза — 720 секунд; для демонстрации можно выбрать меньшую длительность. Ведущий может включить паузу и перейти к следующей фазе вручную.
6. В штабе команды сохраняют общий план. После конца фазы сервер одновременно рассчитывает покупки и удары. После шестого раунда открываются результаты, график развития и история атак.

Сессия хранится в HttpOnly-cookie конкретного браузера на семь дней. Перезагрузка страницы восстанавливает участника. Перенос сессии на другое устройство и восстановление после удаления cookie пока не реализованы. После начала партии новые участники не добавляются.

## Проверки

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run test:e2e
```

`check`: TypeScript, ESLint, границы FSD и Go-тесты. `build`: frontend/dist и .cache/bin. Браузерные проверки охватывают каталог, несколько отдельных сессий, роли, секретность, совместные планы, дипломатию и все шесть раундов.

Windows использует установленный Edge. На Linux сначала выполните `npx playwright install --with-deps chromium`. Тестовый запуск сам поднимает приложение, если оно не запущено. Созданные тестами комнаты остаются в локальном dev-хранилище.

## Docker и production

```sh
docker compose -f deploy/compose.yaml -f deploy/compose.dev.yaml up --build -d
```

Адрес: **http://127.0.0.1:8088**. Compose запускает Caddy, Nginx, четыре Go-сервиса и два PostgreSQL 17 с отдельными volumes. Базы и внутренний gRPC наружу не публикуются.

Для production опубликуйте пять образов приложения: frontend, gateway, catalog, room, world-domination. Скопируйте `deploy/production.env.example` в `deploy/production.env`, задайте домен, digest образов и два независимых случайных пароля БД (hex без специальных символов URL).

```sh
docker compose --env-file deploy/production.env -f deploy/compose.yaml -f deploy/compose.prod.yaml pull
docker compose --env-file deploy/production.env -f deploy/compose.yaml -f deploy/compose.prod.yaml up -d --wait
```

Caddy выпускает HTTPS-сертификаты. Нужны DNS на сервер и доступные порты 80/443. Production включает Secure-cookie и проверку Origin. PostgreSQL сохраняет данные в volumes; перед обновлением делайте резервные копии обеих БД. Автоматический backup, публикация образов и выкладка на реальный сервер не настроены.

Сейчас запускается **по одному экземпляру Room и World Domination**. Горизонтальное масштабирование владельцев партий и обновления без остановки активных игр требуют отдельного механизма координации.

## Контракты и устройство

`contracts/proto/{catalog,room,runtime}/v1` — внутренние RPC; `contracts/http/openapi.yaml` — браузерный API. После изменения:

```sh
npm run generate
node scripts/go.mjs tidy
npm run check
```

Подробности: [архитектура](docs/architecture.md), [формулы и порядок расчёта](docs/world-domination-rules.md).
